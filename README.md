# Appointment Manager

A simple console-based application for managing appointments. This project allows users to add, view, and delete appointments efficiently.

---

## Features
- Add new appointments with a specific date, time, and description.
- List all saved appointments in an organized format.
- Delete unwanted appointments using their corresponding numbers.
- User-friendly menu for seamless navigation.

---

## How to Use
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/Hozan13/AppointmentManager.git
2. Open the project in Visual Studio or your preferred IDE.
3. Build and run the application.
4. Use the menu options:
	1. Add Appointment: Enter a date, time, and description for your appointment.
	2. List Appointments: View all your saved appointments.
	3. Delete Appointment: Remove an appointment by its number.
	4. Exit: Close the application.
